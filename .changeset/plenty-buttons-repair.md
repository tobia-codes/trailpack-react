Move the type declarations for the `styles.css` and `theme.css` exports into
`dist`, where the stylesheets they describe already live. They are generated by
the build now rather than kept by hand in the package root.

Nothing changes for consumers: both stylesheets are imported exactly as before,
and both still resolve to a type, so a side-effect import does not fail with
TS2882 in a project without ambient `*.css` declarations.
